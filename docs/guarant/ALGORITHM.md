# Алгоритм гаранта

Документ описує підтверджену частину алгоритму. Непідтверджені гілки реалізації не вважаються бізнес-правилами.

## Обробка повністю порожнього хвоста

1. Відокремити власника ВС від кандидатів на гарантовані місця.
2. Визначити перше порожнє цільове місце.
3. Перевірити, що всі наступні місця також порожні.
4. Обчислити суму вартостей порожніх місць.
5. Якщо ця сума більша за залишок СО, застосувати R-001:
   - порахувати кількість місць вартістю `1 СО`;
   - обчислити `пропорційний пул = залишок − 1 − кількість місць по 1 СО`;
   - обчислити суму ваг місць із вартістю понад `1 СО`;
   - для поточного місця рекомендувати округлену вгору пропорційну частку;
   - повернути `empty_urgent_proportional_deposit`.
6. Після виконання рекомендації повністю перерахувати залишок, розподіл місць, рейтинг і наступну дію.

Інші гілки алгоритму мають бути описані після підтвердження відповідних правил або кейсів.

## Сторонній вкладник без претендента від гільдії

1. Знайти перше цільове місце зі стороннім вкладником, нижче якого немає учасника гільдії для докидання.
2. Отримати дозвіл власника ВС на перебиття.
3. Якщо дозвіл надано, обчислити кінцевий внесок за R-002:

   `max(внесок стороннього + 1, ceil((внесок стороннього + залишок) / 2))`

4. Перевірити, що рекомендований внесок не перевищує доступний залишок.
5. Після внеску перерахувати рейтинг і переконатися, що сторонній вкладник не може повернути цільове місце, використавши весь новий залишок.
6. Якщо власник заборонив перебиття, не показувати цю ВС на екрані «Гаранти».

## Неперебивний сторонній вкладник

1. Для стороннього вкладника без претендента від гільдії обчислити внесок за R-002.
2. Якщо внесок перевищує залишок ВС, не повертати неможливу рекомендацію.
3. Позначити позицію як неперебивну та продовжити пошук першого наступного проблемного або вільного місця.
4. Для найвищого вільного місця виконати звичайну перевірку гаранту.
5. Якщо гарант власника не потрібен, повернути `empty_guaranteed` із повною вартістю цього місця.

## Вкладник гільдії, якого можна обійти

1. Зупинитися на першому такому вкладнику.
2. Обчислити мінімальний внесок власника за R-004.
3. Не включати до суми гарант наступних порожніх або зайнятих місць.
4. Повернути `guild_member_can_be_overtaken` і дію власника.
5. Після фактичного внеску виконати новий повний розрахунок.

## Вкладник гільдії не доплатив вартість місця

1. Під час обходу місць після пропуску неперебивних сторонніх позицій перевіряти вкладників гільдії згори вниз.
2. Якщо внесок вкладника менший за вартість його місця, зупинити пошук.
3. Обчислити різницю між вартістю місця та фактичним внеском.
4. Повернути `guild_member_below_place_cost` і дію `guild_member_top_up`, адресовану конкретному вкладнику.
5. Не розраховувати гарант нижчих місць до фактичної доплати й нового сканування.

## Вільне місце потребує гаранту власника

1. Після пропуску неперебивних сторонніх позицій знайти найвище вільне місце.
2. Знайти найближчого нижнього стороннього вкладника або використати нуль.
3. Обчислити внесок власника за R-006.
4. Якщо внесок більший за нуль, повернути `empty_requires_owner_guarantee` та дію `owner_deposit`.
5. Не рекомендувати учаснику гільдії заходити на місце до внеску власника.
6. Після внеску власника виконати новий розрахунок; якщо гарант більше не потрібен, повернути `empty_guaranteed` із повною вартістю місця.
