# Оцінка розміру додатку на телефоні

**Оцінка розміру додатку складається з:**
1. **JavaScript-код (React Native, бібліотеки):** 2–10 МБ (залежить від кількості залежностей, оптимізації та використання Hermes).
2. **Зображення, іконки, SVG:** 1–10 МБ (залежить від кількості/розміру локальних ресурсів).
3. **Шрифти, локалізації:** 0.5–2 МБ.
4. **Нативні бібліотеки (Android/iOS):** 10–30 МБ (мінімальний розмір навіть для простого RN-додатку).
5. **Кеш, AsyncStorage, SQLite:** 1–20 МБ (залежить від обсягу локальних даних, історії чатів, зображень, кешу).

**Типові оцінки:**
- **Android (APK/AAB):** 20–50 МБ (release, без heavy assets).
- **iOS (IPA):** 25–60 МБ.
- **Після встановлення:** 30–80 МБ (залежно від пристрою, кешу, оновлень).

**Додатково:**
- Якщо користувач активно використовує чати з фото/файлами, розмір кешу та локальних даних може зрости до 100–200 МБ.
- Якщо всі зображення та файли зберігаються лише у Firebase Storage, а не локально — основний ріст буде лише через кеш.

**Висновок:**  
_Базова інсталяція додатку займе приблизно **30–80 МБ** на телефоні. При активному використанні (фото, кеш) — до 200 МБ і більше._
